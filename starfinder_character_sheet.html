Fill in, save and print Starfinder first edition characters, with Stamina, Hit Points, Resolve, Armor Class, saves and every skill total worked out for you.

🛠️ Import from Hephaistos
  1. On Hephaistos, open your character and use the menu at the top left to download its JSON file.
  2. Choose that file here, or open it in a text editor, copy everything and paste it below, then press Import.

The file is read in your browser and never sent anywhere. Importing the same character again updates its sheet. Hephaistos is a separate fan-made builder; this import is unofficial.

How it works. A sheet auto-saves in this browser once it has a name. Renaming a sheet renames its save. Use the tabs to move between the three pages. Print prints all three pages of the current character, one per US Letter sheet, and Print Blank prints an empty set. Export downloads every sheet as a JSON file and Import merges a file like that back in (a sheet with the same name is replaced). Nothing leaves your browser.

Sample sheets. Load sample characters adds every character from Sample Characters (the 15 solo heroes and all 300 party members) and from Character Examples (the six heroes and the 26 crew members), replacing any saved sheet with the same name just as Import does and leaving your other sheets alone. Each is a full build at its level, with gear bought from the Core Rulebook wealth for that level; party and crew details are in the Notes on the third page. You can also download the sample sheet file and import it yourself.

Import from Hephaistos. Open the panel above, then choose or paste the JSON file Hephaistos downloads for a character. Its abilities, race, theme, classes and levels, Hit Points, Stamina, Resolve, EAC and KAC, saves, skills with ranks, feats, class features, weapons, armor, equipment, augmentations, credits and spells fill the sheet. Where Hephaistos counts a bonus this sheet doesn't (such as feats or class features), the difference goes into the misc boxes so the totals match. The main Import button accepts a Hephaistos file too.

Worked out for you. An ability modifier is (score − 10) ÷ 2, rounded down. Enter a class and level (and a second class if you multiclass) to get base attack bonus and base saves; the seven core classes and the six expansion classes are built in. Key ability defaults to the class's; change it for a soldier, biohacker or evolutionist who uses the other option. Hit Points are your race's HP (once) plus the class HP for each level; Stamina is the class SP + CON modifier for each level; Resolve is half your level (minimum 1) + your key ability modifier. EAC and KAC are 10 + your armor's bonus + DEX modifier (capped by the armor's maximum Dex), and your AC against combat maneuvers is KAC + 8. A skill total is ranks + ability modifier, +3 for a class skill with at least one rank, minus the armor check penalty where it applies. Bulk counts 10 light (L) items as 1; you are encumbered above half your STR score and overburdened above your STR score. See Character Creation, Classes and the Dice Roller.
